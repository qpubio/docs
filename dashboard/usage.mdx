The **Usage** page shows how a project consumes connections, messages, channels, and bandwidth over a time range. Use it to compare traffic against your [plan limits](/pricing/limits.mdx).

Open a project in the dashboard, then select the **Usage** tab.

## Choose a time range

Use the clock control in the page header.

**Quick ranges** include **Last 5 minutes** through **Last 5 years** (for example **Last 1 hour**, **Last 24 hours**, **Last 7 days**). The default is **Last 1 hour**.

You can also pick a **custom** start and end date in the calendar, then **Apply**. Future dates are disabled.

The header button shows the active quick-range name, or a formatted start–end range for custom selections.

## Charts

Six live charts (history for the selected range):

| Chart | Series |
|-------|--------|
| **Connections** | Peak Connections, Average Connections, Total Connection Time |
| **Messages** | Published Messages, Delivered Messages, Total Messages |
| **Channels** | Peak Channels, Average Channels, Total Channel Time |
| **Subscribers** | Peak Subscribers, Average Subscribers |
| **Message Size** | Total Message Size, Average Message Size |
| **Bandwidth** | Total Bandwidth, Average Bandwidth |

Charts support horizontal zoom along the time axis.

## Summary table

Below the charts, **Summary** lists aggregated metrics for a date window shown in the card subtitle.

Columns: **Metric** | **Usage**.

Rows include peak/average connections and channels, connection and channel time (minutes), peak/average subscribers, messages published/delivered/total, message size totals/averages, and bandwidth totals/averages.

When you use a **quick range**, the summary window matches the charts. For a **custom** range, confirm the Summary subtitle if it differs from the header picker.

## If data fails to load

The page may show **Unable to load usage data**. Refresh the page or pick a different time range.

## Related

- Messaging clients do not call Usage APIs—only the dashboard (signed-in users).
- Live chart updates can relate to API key **Statistics** permission (configured under [API Keys](/dashboard/api-keys.mdx)).
