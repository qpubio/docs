The dashboard shows **usage** for a project so you can compare consumption to your [plan limits](/docs/pricing/limits).

## What to watch

Typical metrics tied to plan limits include:

- Concurrent connections
- Message volume (hourly / monthly)
- Bandwidth
- Concurrent channels
- Message size

Exact charts and labels are defined in the dashboard UI.

## Workflow

1. Open a project.
2. Open **Usage** (summary and history where available).
3. If you are approaching limits, reduce traffic or [upgrade your plan](/docs/pricing/plans).

Usage data is also available to signed-in dashboard users via the dashboard API; messaging clients do not call those endpoints.
