---

A **project** isolates messaging traffic, API keys, queues, and usage. Create projects from the dashboard after you have an account.

## Common tasks

1. **Create** a project with a clear name (for example `production` or `staging`).
2. **Open** the project to manage keys, usage, and the console.
3. **Update** project settings when renaming or adjusting metadata.
4. **Delete** a project when it is no longer needed (irreversible for that project’s resources).

## Tips

- Use separate projects for environments (dev / staging / prod).
- Create environment-specific API keys under each project.
- Monitor [usage](/docs/dashboard/usage) per project against your [plan limits](/docs/pricing/limits).
