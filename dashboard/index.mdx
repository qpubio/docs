The QPub dashboard is the web UI for account and project management. Messaging clients do not use dashboard login credentials; they use [API keys or tokens](/docs/core/auth).

## What you can do

| Area | Purpose |
|------|---------|
| [Accounts](/docs/dashboard/accounts) | Profile, sign-in, invitations |
| [Projects](/docs/dashboard/projects) | Create and manage projects |
| [API Keys](/docs/dashboard/api-keys) | Create credentials for Socket/REST |
| [Usage](/docs/dashboard/usage) | Inspect consumption against plan limits |
| [Console](/docs/dashboard/console) | Interactive project console for testing |

## Sign-up flow

1. Create a user account (email/password or OAuth).
2. Create or join an account organization.
3. Create a project.
4. Create an API key.
5. Use the key with `@qpub/sdk` or the REST/Socket APIs.

Billing and plan changes are handled in the dashboard (Stripe checkout). See [Pricing](/docs/pricing/plans).
