## Documentation

This site’s content lives in the public `docs` repository (MDX + `sidebar.json`).

1. Edit or add an MDX page under the correct folder.
2. Update `sidebar.json` if you add or rename a page.
3. Follow terminology and hosts in the docs `README.md`.
4. Do not invent APIs — verify against `qpub-backend` and `@qpub/sdk`.

## JavaScript SDK

The official SDK is open source: [`qpub-js`](https://github.com/qpubio/qpub-js) (`@qpub/sdk`).

- Open issues for bugs and feature requests.
- Prefer pull requests with tests for SDK changes.
