Product and SDK release notes are published with each release.

- JS/TS SDK (`@qpub/sdk`): [releases on `qpub-js`](https://github.com/qpubio/qpub-js/releases)
- Go SDK: [releases on `qpub-go`](https://github.com/qpubio/qpub-go/releases)
- Platform / API changes: announced with Cloud or release notes when shipped.

## Documentation

Recent docs updates:

- Multi-language examples (JavaScript, TypeScript, React, Go, cURL) with shared docs chrome
- Aligned customer docs with public REST/Socket APIs and official SDKs
- Documented queues (`rest.queues` and REST queue endpoints)
- Corrected auth, hosts, and protocol guidance for custom clients
