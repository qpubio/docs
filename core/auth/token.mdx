---
title: "Token Auth"
description: "Issue and use short-lived JWTs for QPub clients."
---

JWTs give clients temporary access without exposing the API key secret. Tokens are issued from an API key and can carry an **alias** and **permission** scope.

Use the **API** and **Language** controls to switch **Socket** vs **REST** and **JavaScript**, **React**, or **Go**.

<ExampleScope defaultGroup="Socket" groups={["Socket", "REST"]} languages={["javascript", "react", "go"]}>

## Using a token

<When group="Socket">

Connect with a JWT via query/`access_token`, or let the SDK fetch one:

```
wss://socket.qpub.io/v1?access_token=<jwt>
```

<CodeExamples group="Socket">

```javascript
import { QPub } from "@qpub/sdk";

const socket = new QPub.Socket({
  authUrl: "https://your-app.example/api/qpub-token",
});
// Your authUrl should return { token: "<jwt>" }
```

```react
import { SocketProvider } from "@qpub/sdk/react";

function App() {
  return (
    <SocketProvider
      options={{
        authUrl: "https://your-app.example/api/qpub-token",
      }}
    >
      {children}
    </SocketProvider>
  );
}
```

```go
import (
	"github.com/qpubio/qpub-go/qpub"
)

socket := qpub.NewSocket(func(o *qpub.Option) {
	o.AuthURL = "https://your-app.example/api/qpub-token"
})
defer socket.Reset()
// Your authUrl should return { "token": "<jwt>" }
```

</CodeExamples>

</When>

<When group="REST">

Call REST with a Bearer JWT:

```bash
curl -X POST "https://rest.qpub.io/v1/channel/demo/messages" \
  -H "Authorization: Bearer <jwt>" \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"data":{"text":"Hello"}}]}'
```

On a trusted server you usually keep using `QPub.Rest({ apiKey })` instead of a JWT. For browsers, mint a JWT (or token request) on your backend and call REST with `Authorization: Bearer <jwt>` — or use **Socket** for realtime clients.

</When>

## Issue a token (server)

Always mint tokens on a **trusted server** with the API key secret. This step is the same regardless of whether clients use Socket or REST.

### REST endpoint

```
POST /v1/key/:keyID/token/issue
Authorization: Basic <base64(publicId:secret)>
```

`:keyID` is the API key **public** id.

Body (all optional):

```json
{
  "alias": "web-client-1",
  "permission": {
    "notifications": ["subscribe"],
    "*": ["subscribe"]
  },
  "expiresIn": 3600
}
```

`expiresIn` is seconds (camelCase in the JSON body). Permission keys are channel resource names; see [Permissions](/core/auth/permissions.mdx).

**200** response:

```json
{ "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." }
```

### SDK

<CodeExamples>

```javascript
import { QPub } from "@qpub/sdk";

const rest = new QPub.Rest({ apiKey: process.env.QPUB_API_KEY });

const token = await rest.auth.issueToken({
  alias: "web-client-1",
  permission: { notifications: ["subscribe"] },
  expiresIn: 3600,
});
```

```go
import (
	"context"
	"log"
	"os"

	"github.com/qpubio/qpub-go/qpub"
)

rest := qpub.NewRest(qpub.WithAPIKey(os.Getenv("QPUB_API_KEY")))
defer rest.Reset()

token, err := rest.Auth.IssueToken(context.Background(), qpub.TokenOptions{
	Alias:      "web-client-1",
	Permission: qpub.Permission{"notifications": {"subscribe"}},
	ExpiresIn:  3600,
})
if err != nil {
	log.Fatal(err)
}
_ = token
```

</CodeExamples>

`generateToken` / `GenerateToken` signs a JWT locally with the API key secret (convenient for trusted servers). Prefer `issueToken` / `IssueToken` when you want the platform to mint the token.

## Token request

For untrusted clients, create a **signed token request** on your server, send it to the client, and let the client exchange it for a JWT. The secret never leaves your server.

### Server

<CodeExamples>

```javascript
import { QPub } from "@qpub/sdk";

const rest = new QPub.Rest({ apiKey: process.env.QPUB_API_KEY });

const tokenRequest = await rest.auth.createTokenRequest({
  alias: "Alice",
  permission: { "chat.lobby": ["subscribe", "publish"] },
});
// Return tokenRequest to the client
```

```go
import (
	"context"
	"log"
	"os"

	"github.com/qpubio/qpub-go/qpub"
)

rest := qpub.NewRest(qpub.WithAPIKey(os.Getenv("QPUB_API_KEY")))
defer rest.Reset()

tokenRequest, err := rest.Auth.CreateTokenRequest(context.Background(), qpub.TokenOptions{
	Alias:      "Alice",
	Permission: qpub.Permission{"chat.lobby": {"subscribe", "publish"}},
})
if err != nil {
	log.Fatal(err)
}
// Return tokenRequest to the client
_ = tokenRequest
```

</CodeExamples>

### Client

<When group="Socket">

<CodeExamples group="Socket">

```javascript
const socket = new QPub.Socket({
  tokenRequest, // auto-requests a token on init when provided
});

// Or: await socket.auth.requestToken(tokenRequest);
```

```react
function App({ tokenRequest }) {
  return (
    <SocketProvider options={{ tokenRequest }}>
      {children}
    </SocketProvider>
  );
}
```

```go
import (
	"github.com/qpubio/qpub-go/qpub"
)

socket := qpub.NewSocket(func(o *qpub.Option) {
	o.TokenRequest = &tokenRequest // from your server
})
defer socket.Reset()
// Or: _, err := socket.Auth.RequestToken(ctx, tokenRequest)
```

</CodeExamples>

</When>

<When group="REST">

Exchange the token request for a JWT, then call REST with Bearer auth. Prefer Socket + `tokenRequest` for browser realtime clients.

<CodeExamples group="REST">

```javascript
import { QPub } from "@qpub/sdk";

const rest = new QPub.Rest();
const { token } = await rest.auth.requestToken(tokenRequest);

await fetch("https://rest.qpub.io/v1/channel/demo/messages", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${token}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    messages: [{ data: { text: "Hello" } }],
  }),
});
```

```go
import (
	"context"
	"log"

	"github.com/qpubio/qpub-go/channel"
	"github.com/qpubio/qpub-go/qpub"
)

ctx := context.Background()
rest := qpub.NewRest()
defer rest.Reset()

if _, err := rest.Auth.RequestToken(ctx, tokenRequest); err != nil {
	log.Fatal(err)
}

_, err := rest.Channels.Get("demo").Publish(ctx, map[string]string{"text": "Hello"}, channel.PublishOptions{})
if err != nil {
	log.Fatal(err)
}
```

</CodeExamples>

</When>

### REST exchange

```
POST /v1/key/:keyID/token/request
Content-Type: application/json
```

Body includes `aki`, `timestamp`, optional `alias` / `permission`, and `signature` (HMAC-SHA256 over a canonical string). Prefer the SDK helpers instead of signing by hand.

**200** response (same shape as issue):

```json
{ "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." }
```

## Auth events (SDK)

<When group="Socket">

Listen on `socket.auth`:

- `token_updated`
- `token_expired`
- `token_error`
- `auth_error`

<When lang="go">
Register callbacks on `socket.Auth` with `qpub.AuthEvents` (for example `TokenUpdated`, `TokenExpired`).
</When>

</When>

<When group="REST">

Auth lifecycle events (`token_updated`, `token_expired`, …) are exposed on the **Socket** client’s `socket.auth`. REST calls fail with HTTP errors when a JWT is missing or expired — refresh via your backend and retry.

</When>

</ExampleScope>
