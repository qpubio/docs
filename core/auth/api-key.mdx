---
title: "API Key Auth"
description: "Authenticate to REST and WebSocket with a project API key."
---

API keys are project credentials in the form:

```
<publicId>:<secret>
```

Create and rotate keys in [QPub Cloud](/cloud/api-keys.mdx).

<ExampleScope defaultGroup="REST" groups={["REST", "Socket"]} languages={["javascript", "typescript", "react", "go", "curl"]}>

## REST

<When group="REST">

Send the key as HTTP Basic (recommended):

<CodeExamples group="REST">

```javascript
import { QPub } from "@qpub/sdk";

const rest = new QPub.Rest({
  apiKey: process.env.QPUB_API_KEY,
});

await rest.channels.get("demo").publish({ text: "Hello" });
```

```typescript
import { QPub } from "@qpub/sdk";

const rest = new QPub.Rest({
  apiKey: process.env.QPUB_API_KEY,
});
```

```go
rest := qpub.NewRest(qpub.WithAPIKey(os.Getenv("QPUB_API_KEY")))
defer rest.Reset()
```

```curl
API_KEY="publicId:secret"
curl -X POST "https://rest.qpub.io/v1/channel/demo/messages" \
  -H "Authorization: Basic $(echo -n "$API_KEY" | base64)" \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"data":{"text":"Hello"}}]}'
```

</CodeExamples>

</When>

Or as a query parameter (less preferred — may appear in logs):

```
?api_key=<url-encoded publicId:secret>
```

Optional client identity:

```
X-Alias: my-server
```

## WebSocket

Connect to `wss://socket.qpub.io/v1` with:

```
?api_key=<url-encoded publicId:secret>
```

Optional: `&alias=my-client`.

<When group="Socket">

## SDK

<CodeExamples group="Socket">

```javascript
import { QPub } from "@qpub/sdk";

const socket = new QPub.Socket({
  apiKey: process.env.QPUB_API_KEY,
  alias: "server-worker-1",
});

const rest = new QPub.Rest({
  apiKey: process.env.QPUB_API_KEY,
});
```

```typescript
import { QPub } from "@qpub/sdk";

const socket = new QPub.Socket({
  apiKey: process.env.QPUB_API_KEY,
  alias: "server-worker-1",
});

const rest = new QPub.Rest({
  apiKey: process.env.QPUB_API_KEY,
});
```

```react
<SocketProvider options={{ apiKey: process.env.QPUB_API_KEY, alias: "server-worker-1" }}>
  {children}
</SocketProvider>
```

```go
socket := qpub.NewSocket(qpub.WithAPIKey(os.Getenv("QPUB_API_KEY")))
rest := qpub.NewRest(qpub.WithAPIKey(os.Getenv("QPUB_API_KEY")))
```

</CodeExamples>

The SDK sends Basic auth on REST and `api_key` on the WebSocket URL when no JWT is active.

</When>

</ExampleScope>

## Security

- Use API keys only on trusted servers.
- For browsers, use [Token Auth](/core/auth/token.mdx).
- Scope keys with [permissions](/core/auth/permissions.mdx) when creating them in QPub Cloud.
- Rotate keys if a secret leaks.
