---
title: "Workers"
description: "Pull, ack, and nack jobs with external workers."
---

External workers are processes you run. Registration is optional metadata; pull authorization uses your API key or JWT permissions.

<ExampleScope defaultGroup="REST" groups={["REST"]} languages={["javascript", "typescript", "go", "curl"]}>

## High-level SDK loop

<CodeExamples group="REST">

```javascript
const rest = new QPub.Rest({ apiKey: process.env.QPUB_API_KEY });

const worker = await rest.queues.registerWorker({
  name: "email-worker",
  queues: ["emails"],
});

await rest.queues.runWorker(
  "emails",
  async (job) => {
    return { ok: true };
  },
  {
    workerId: worker.id,
    batchSize: 1,
    pollIntervalMs: 1000,
    wait: "20s",
  }
);
```

```typescript
const rest = new QPub.Rest({ apiKey: process.env.QPUB_API_KEY });

const worker = await rest.queues.registerWorker({
  name: "email-worker",
  queues: ["emails"],
});

await rest.queues.runWorker(
  "emails",
  async (job) => {
    return { ok: true };
  },
  {
    workerId: worker.id,
    batchSize: 1,
    pollIntervalMs: 1000,
    wait: "20s",
  }
);
```

```go
import (
	"context"

	"github.com/qpubio/qpub-go/protocol"
)

worker, err := rest.Queues.RegisterWorker(ctx, protocol.RegisterWorkerOptions{
	Name:   "email-worker",
	Queues: []string{"emails"},
})
_ = rest.Queues.RunWorker(ctx, "emails", func(ctx context.Context, job protocol.QueueJob) (interface{}, error) {
	return map[string]bool{"ok": true}, nil
}, protocol.RunWorkerOptions{WorkerID: worker.ID})
```

```curl
API_KEY="publicId:secret"
curl -X POST "https://rest.qpub.io/v1/queue/emails/pull" \
  -H "Authorization: Basic $(echo -n "$API_KEY" | base64)" \
  -H "Content-Type: application/json" \
  -d '{"worker_id":"01J...","batch_size":1,"wait":"5s"}'
```

</CodeExamples>

`runWorker` blocks until `stopWorker()` is called.

## Low-level pull / ack / nack

```
POST /v1/queue/:queueName/pull
POST /v1/queue/:queueName/jobs/:jobId/ack
POST /v1/queue/:queueName/jobs/:jobId/nack
```

Pull body:

```json
{
  "worker_id": "01J...",
  "batch_size": 1,
  "wait": "5s"
}
```

Ack:

```json
{ "worker_id": "01J...", "result": { "ok": true } }
```

Nack:

```json
{
  "worker_id": "01J...",
  "reason": "temporary failure",
  "retry_delay": "30s"
}
```

## Register and heartbeat

```
POST /v1/workers/register
POST /v1/workers/heartbeat
```

<CodeExamples group="REST">

```javascript
await rest.queues.registerWorker({ name: "email-worker", queues: ["emails"] });
await rest.queues.heartbeat(workerId);
```

```typescript
await rest.queues.registerWorker({ name: "email-worker", queues: ["emails"] });
await rest.queues.heartbeat(workerId);
```

```go
w, err := rest.Queues.RegisterWorker(ctx, protocol.RegisterWorkerOptions{
	Name: "email-worker", Queues: []string{"emails"},
})
_ = rest.Queues.Heartbeat(ctx, w.ID)
```

```curl
API_KEY="publicId:secret"
curl -X POST "https://rest.qpub.io/v1/workers/register" \
  -H "Authorization: Basic $(echo -n "$API_KEY" | base64)" \
  -H "Content-Type: application/json" \
  -d '{"name":"email-worker","queues":["emails"]}'
```

</CodeExamples>

The `queues` array on registration is declarative metadata. It does not replace permission checks on pull.
