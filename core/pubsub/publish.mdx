Publish to a named channel with `publish` permission. Use the **API** and **Language** controls to switch **Socket** vs **REST** and the sample language.

<ExampleScope defaultGroup="Socket" groups={["Socket", "REST"]} languages={["javascript", "typescript", "react", "go", "curl"]}>

## Publish a message

<When group="Socket">

Publish over the WebSocket client after you are connected.

<CodeExamples group="Socket">

```javascript
import { QPub } from "@qpub/sdk";

const socket = new QPub.Socket({
  apiKey: process.env.QPUB_API_KEY,
});

socket.connection.on("connected", async () => {
  const channel = socket.channels.get("notifications");
  await channel.publish(
    { title: "New order", orderId: "ord_1" },
    { event: "order.created", alias: "api" }
  );
});
```

```typescript
import { QPub } from "@qpub/sdk";

const socket = new QPub.Socket({
  apiKey: process.env.QPUB_API_KEY,
});

socket.connection.on("connected", async () => {
  const channel = socket.channels.get("notifications");
  await channel.publish(
    { title: "New order", orderId: "ord_1" },
    { event: "order.created", alias: "api" }
  );
});
```

```react
import { SocketProvider, useChannel } from "@qpub/sdk/react";

function App() {
  return (
    <SocketProvider options={{ apiKey: process.env.QPUB_API_KEY }}>
      <PublishButton />
    </SocketProvider>
  );
}

function PublishButton() {
  const { publish, ready } = useChannel("notifications");

  return (
    <button
      disabled={!ready}
      onClick={() =>
        publish(
          { title: "New order", orderId: "ord_1" },
          { event: "order.created" }
        )
      }
    >
      Publish
    </button>
  );
}
```

```go
package main

import (
	"context"
	"log"
	"os"

	"github.com/qpubio/qpub-go/channel"
	"github.com/qpubio/qpub-go"
)

func main() {
	socket := qpub.NewSocket(qpub.WithAPIKey(os.Getenv("QPUB_API_KEY")))
	defer socket.Reset()

	ctx := context.Background()
	if err := socket.Connection.WaitUntilConnected(ctx); err != nil {
		log.Fatal(err)
	}

	ch := socket.Channels.Get("notifications")
	err := ch.Publish(ctx, map[string]interface{}{
		"title":   "New order",
		"orderId": "ord_1",
	}, channel.PublishOptions{Event: "order.created", Alias: "api"})
	if err != nil {
		log.Fatal(err)
	}
}
```

</CodeExamples>

Socket publish does not return the REST `published` payload.

<When lang="react">
Prefer a JWT or [token request](/core/auth/token.mdx) in `SocketProvider` for browsers instead of a production API key secret.
</When>

<When lang="go">
Keep the API key on a trusted server or use [token auth](/core/auth/token.mdx) for credentials issued to other clients.
</When>

</When>

<When group="REST">

Publish over HTTP with the REST client (`https://rest.qpub.io/v1`).

<CodeExamples group="REST">

```javascript
import { QPub } from "@qpub/sdk";

const rest = new QPub.Rest({
  apiKey: process.env.QPUB_API_KEY,
});

await rest.channels.get("notifications").publish(
  { title: "New order" },
  { event: "order.created" }
);
```

```typescript
import { QPub } from "@qpub/sdk";

const rest = new QPub.Rest({
  apiKey: process.env.QPUB_API_KEY,
});

await rest.channels.get("notifications").publish(
  { title: "New order" },
  { event: "order.created" }
);
```

```react
import { useState } from "react";
import { QPub } from "@qpub/sdk";

const rest = new QPub.Rest({
  apiKey: process.env.QPUB_API_KEY, // trusted / server-only env
});

export function PublishButton() {
  const [busy, setBusy] = useState(false);

  return (
    <button
      disabled={busy}
      onClick={async () => {
        setBusy(true);
        try {
          await rest.channels.get("notifications").publish(
            { title: "New order" },
            { event: "order.created" }
          );
        } finally {
          setBusy(false);
        }
      }}
    >
      Publish
    </button>
  );
}
```

```go
package main

import (
	"context"
	"log"
	"os"

	"github.com/qpubio/qpub-go/channel"
	"github.com/qpubio/qpub-go"
)

func main() {
	rest := qpub.NewRest(qpub.WithAPIKey(os.Getenv("QPUB_API_KEY")))
	defer rest.Reset()

	_, err := rest.Channels.Get("notifications").Publish(
		context.Background(),
		map[string]string{"title": "New order"},
		channel.PublishOptions{Event: "order.created"},
	)
	if err != nil {
		log.Fatal(err)
	}
}
```

```curl
API_KEY="publicId:secret"
curl -X POST "https://rest.qpub.io/v1/channel/notifications/messages" \
  -H "Authorization: Basic $(echo -n "$API_KEY" | base64)" \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"event":"order.created","data":{"title":"New order"}}]}'
```

</CodeExamples>

HTTP:

```
POST /v1/channel/:channelName/messages
```

```json
{
  "messages": [
    {
      "event": "order.created",
      "data": { "title": "New order" }
    }
  ]
}
```

Successful publishes return **201** with a `published` array (`channel`, `message_id`, `published_at`, `payload_count`). Partial multi-channel failures may return **207** (`PARTIAL_CONTENT`) with those fields under `details`.

<When lang={["javascript", "typescript"]}>
Run REST publish from a trusted server or script that can hold the API key secret.
</When>

<When lang="react">
QPub's React hooks/providers (`@qpub/sdk/react`) are Socket-only. REST is recommended for **server-side** use, so there's no dedicated React integration — but you can still call the plain `QPub.Rest` client from React (an event handler or server action). Keep secrets off the public client bundle.
</When>

<When lang="go">
REST publish is intended for trusted Go services and workers.
</When>

</When>

## Batch publish (REST)

<When group="REST">

Publish the same messages to multiple channels:

<CodeExamples group="REST">

```javascript
await rest.channels.publishBatch(
  ["notifications", "ops"],
  [
    { data: { title: "New order" }, event: "order.created" },
  ]
);
```

```typescript
await rest.channels.publishBatch(
  ["notifications", "ops"],
  [
    { data: { title: "New order" }, event: "order.created" },
  ]
);
```

```react
await rest.channels.publishBatch(
  ["notifications", "ops"],
  [
    { data: { title: "New order" }, event: "order.created" },
  ]
);
```

```go
import (
	"encoding/json"

	"github.com/qpubio/qpub-go/protocol"
)

payload, _ := json.Marshal(map[string]string{"title": "New order"})
_, err := rest.Channels.PublishBatch(
	context.Background(),
	[]string{"notifications", "ops"},
	[]protocol.DataMessagePayload{{
		Event: "order.created",
		Data:  payload,
	}},
)
```

```curl
API_KEY="publicId:secret"
curl -X POST "https://rest.qpub.io/v1/channels/messages" \
  -H "Authorization: Basic $(echo -n "$API_KEY" | base64)" \
  -H "Content-Type: application/json" \
  -d '{"channels":["notifications","ops"],"messages":[{"event":"order.created","data":{"title":"New order"}}]}'
```

</CodeExamples>

<When lang="react">
Again, there is no React-specific REST API — `QPub.Rest` is a plain client you can call from React (server actions or event handlers).
</When>

HTTP:

```
POST /v1/channels/messages
```

```json
{
  "channels": ["notifications", "ops"],
  "messages": [
    { "event": "order.created", "data": { "title": "New order" } }
  ]
}
```

</When>

<When group="Socket">

Batch publish to multiple channels is a **REST** feature (`publishBatch` / `POST /v1/channels/messages`). Switch to **REST** above, or publish once per channel on the Socket.

</When>

## Notes

- At least one message is required in the REST body.
- Message size and rate limits depend on your [plan](/pricing/limits.mdx).
- Subscribers need a [Socket subscription](/core/pubsub/subscribe.mdx) to receive messages in realtime.

</ExampleScope>
