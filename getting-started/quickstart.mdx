title: "Quickstart"
description: "Connect with the JavaScript SDK, subscribe to a channel, and publish a message."
---

Get a working pub/sub loop with `@qpub/sdk` in a few minutes.

## Prerequisites

- A QPub account and project
- An API key from the [dashboard](/docs/dashboard/api-keys)
- Node.js, Bun, or a browser environment

## 1. Install

```bash
npm install @qpub/sdk
```

## 2. Subscribe (Socket)

```javascript
import { QPub } from "@qpub/sdk";

const socket = new QPub.Socket({
  apiKey: process.env.QPUB_API_KEY,
});

socket.connection.on("connected", async () => {
  const channel = socket.channels.get("demo");
  await channel.subscribe((message) => {
    console.log("received", message.data, message.event);
  });
});
```

By default the Socket client connects automatically (`autoConnect: true`) to `wss://socket.qpub.io/v1`.

> Do not put a production API key secret in a public browser app. Use [token auth](/docs/core/auth/token) instead.

## 3. Publish (REST)

In another process (or tab), publish with the REST client:

```javascript
import { QPub } from "@qpub/sdk";

const rest = new QPub.Rest({
  apiKey: process.env.QPUB_API_KEY,
});

await rest.channels.get("demo").publish(
  { text: "Hello, QPub!" },
  { event: "greeting" }
);
```

Or publish from the same Socket after you are connected:

```javascript
await socket.channels.get("demo").publish(
  { text: "Hello from socket" },
  { event: "greeting" }
);
```

## 4. Optional: event filter

```javascript
await channel.subscribe(
  (message) => console.log(message.data),
  { event: "greeting" }
);
```

## Local development

Override hosts when pointing at a local QPub stack:

```javascript
const socket = new QPub.Socket({
  apiKey: process.env.QPUB_API_KEY,
  wsHost: "localhost",
  wsPort: 8131,
  isSecure: false,
});

const rest = new QPub.Rest({
  apiKey: process.env.QPUB_API_KEY,
  httpHost: "localhost",
  httpPort: 8111,
  isSecure: false,
});
```
