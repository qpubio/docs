Get a working pub/sub loop with `@qpub/sdk` in a few minutes. Use the **API** and **Language** controls (right rail on large screens; on smaller screens, open the docs navigation drawer at the bottom of the page) to switch **Socket** vs **REST** and **JavaScript** vs **React** — samples and notes update together.

<ExampleScope defaultGroup="Socket" groups={["Socket", "REST"]} languages={["javascript", "react"]}>

## Prerequisites

- A QPub account and project
- An API key from [QPub Cloud](/cloud/api-keys.mdx)
- Node.js, Bun, or a browser environment

## 1. Install

```bash
npm install @qpub/sdk
```

<When lang="react">
Import providers and hooks from `@qpub/sdk/react` (same package).
</When>

## 2. Receive or publish

<When group="Socket">

Subscribe over the WebSocket client. By default the Socket connects automatically (`autoConnect: true`) to `wss://socket.qpub.io/v1`.

<CodeExamples group="Socket">

```javascript
import { QPub } from "@qpub/sdk";

const socket = new QPub.Socket({
  apiKey: process.env.QPUB_API_KEY,
});

socket.connection.on("connected", async () => {
  const channel = socket.channels.get("demo");
  await channel.subscribe((message) => {
    console.log("received", message.data, message.event);
  });
});
```

```react
import { useCallback, useEffect } from "react";
import {
  SocketProvider,
  useChannel,
  useConnection,
  type Message,
} from "@qpub/sdk/react";

function App() {
  return (
    <SocketProvider options={{ apiKey: process.env.QPUB_API_KEY }}>
      <Demo />
    </SocketProvider>
  );
}

function Demo() {
  const { status } = useConnection();
  const { subscribe, unsubscribe, ready } = useChannel("demo");

  const onMessage = useCallback((message: Message) => {
    console.log("received", message.data, message.event);
  }, []);

  useEffect(() => {
    if (!ready) return;
    subscribe(onMessage);
    return () => {
      unsubscribe(onMessage);
    };
  }, [ready, subscribe, unsubscribe, onMessage]);

  return <p>Status: {status}</p>;
}
```

</CodeExamples>

<When lang="javascript">
> Do not put a production API key secret in a public browser app. Use [token auth](/core/auth/token.mdx) instead.
</When>

<When lang="react">
Prefer a JWT or [token request](/core/auth/token.mdx) in `SocketProvider` options instead of embedding a production API key secret in the browser bundle.
</When>

</When>

<When group="REST">

Publish over HTTP with the REST client (`https://rest.qpub.io/v1`). REST does not open a realtime subscription — switch to **Socket** above to receive messages.

<CodeExamples group="REST">

```javascript
import { QPub } from "@qpub/sdk";

const rest = new QPub.Rest({
  apiKey: process.env.QPUB_API_KEY,
});

await rest.channels.get("demo").publish(
  { text: "Hello, QPub!" },
  { event: "greeting" }
);
```

```react
import { useState } from "react";
import { QPub } from "@qpub/sdk";

const rest = new QPub.Rest({
  apiKey: process.env.QPUB_API_KEY, // trusted / server-only env
});

export function PublishButton() {
  const [busy, setBusy] = useState(false);

  return (
    <button
      disabled={busy}
      onClick={async () => {
        setBusy(true);
        try {
          await rest.channels.get("demo").publish(
            { text: "Hello, QPub!" },
            { event: "greeting" }
          );
        } finally {
          setBusy(false);
        }
      }}
    >
      Publish
    </button>
  );
}
```

</CodeExamples>

<When lang="javascript">
Run this from a trusted server or script that can hold the API key secret.
</When>

<When lang="react">
Call REST from an event handler or server action. Keep secrets off the public client bundle — use a JWT / [token request](/core/auth/token.mdx) for browsers.
</When>

</When>

## 3. Complete the loop

<When group="Socket">

In another process (or tab), publish with REST:

```javascript
import { QPub } from "@qpub/sdk";

const rest = new QPub.Rest({
  apiKey: process.env.QPUB_API_KEY,
});

await rest.channels.get("demo").publish(
  { text: "Hello, QPub!" },
  { event: "greeting" }
);
```

Or publish from the same Socket after you are connected:

<CodeExamples group="Socket">

```javascript
await socket.channels.get("demo").publish(
  { text: "Hello from socket" },
  { event: "greeting" }
);
```

```react
const { publish, ready } = useChannel("demo");

<button
  disabled={!ready}
  onClick={() =>
    publish({ text: "Hello from socket" }, { event: "greeting" })
  }
>
  Send
</button>
```

</CodeExamples>

</When>

<When group="REST">

Your publish call above is enough for the REST path. To see messages arrive in realtime, switch **API** to **Socket** and run the subscribe sample (or open a second client).

</When>

## 4. Optional: event filter

<When group="Socket">

<CodeExamples group="Socket">

```javascript
await channel.subscribe(
  (message) => console.log(message.data),
  { event: "greeting" }
);
```

```react
const { subscribe, unsubscribe, ready } = useChannel("demo");

useEffect(() => {
  if (!ready) return;
  const onMessage = (message) => console.log(message.data);
  subscribe(onMessage, { event: "greeting" });
  return () => unsubscribe(onMessage);
}, [ready, subscribe, unsubscribe]);
```

</CodeExamples>

</When>

<When group="REST">

Event filters apply on the **subscriber** (Socket). Pass `{ event: "greeting" }` as the second argument to `publish` so subscribers that filter on that event receive the message.

</When>

## Local development

Override hosts when pointing at a local QPub stack:

<CodeExamples>

```javascript
const socket = new QPub.Socket({
  apiKey: process.env.QPUB_API_KEY,
  wsHost: "localhost",
  wsPort: 8131,
  isSecure: false,
});

const rest = new QPub.Rest({
  apiKey: process.env.QPUB_API_KEY,
  httpHost: "localhost",
  httpPort: 8111,
  isSecure: false,
});
```

```react
const socketOptions = {
  apiKey: process.env.QPUB_API_KEY,
  wsHost: "localhost",
  wsPort: 8131,
  isSecure: false,
};

const rest = new QPub.Rest({
  apiKey: process.env.QPUB_API_KEY,
  httpHost: "localhost",
  httpPort: 8111,
  isSecure: false,
});

// Socket path:
<SocketProvider options={socketOptions}>{children}</SocketProvider>
```

</CodeExamples>
