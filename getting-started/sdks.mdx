QPub ships official client libraries: `@qpub/sdk` (JavaScript/TypeScript) and [qpub-go](https://github.com/qpubio/qpub-go) (Go). Use the **API** and **Language** controls to switch **Socket** vs **REST** and **JavaScript** vs **React** vs **Go**.

<ExampleScope defaultGroup="Socket" groups={["Socket", "REST"]} languages={["javascript", "react", "go"]}>

## Install

<When lang="javascript">
```bash
npm install @qpub/sdk
# or
bun add @qpub/sdk
```
</When>

<When lang="react">
```bash
npm install @qpub/sdk
```
Import providers and hooks from `@qpub/sdk/react` (same package).
</When>

<When lang="go">
```bash
go get github.com/qpubio/qpub-go@v0.1.0
```
Requires Go 1.22 or newer.
</When>

| Import | Use |
|--------|-----|
| `@qpub/sdk` | `QPub.Socket`, `QPub.Rest`, types (JavaScript) |
| `@qpub/sdk/react` | React providers and hooks |
| `github.com/qpubio/qpub-go/qpub` | `qpub.NewSocket`, `qpub.NewRest` (Go) |
| CDN UMD | Global `QPub` in the browser |

## Quick example

<When group="Socket">

Use the Socket client for realtime subscribe and publish:

<CodeExamples group="Socket">

```javascript
import { QPub } from "@qpub/sdk";

const socket = new QPub.Socket({
  apiKey: process.env.QPUB_API_KEY,
});

socket.connection.on("connected", async () => {
  const ch = socket.channels.get("news");
  await ch.subscribe((msg) => console.log(msg.data));
});
```

```react
import { useCallback, useEffect } from "react";
import {
  SocketProvider,
  useChannel,
  useConnection,
  type Message,
} from "@qpub/sdk/react";

function App({ tokenRequest }) {
  return (
    <SocketProvider options={{ tokenRequest }}>
      <Chat />
    </SocketProvider>
  );
}

function Chat() {
  const { status } = useConnection();
  const { publish, subscribe, unsubscribe, ready } = useChannel("chat");

  const onMessage = useCallback((message: Message) => {
    console.log(message.data);
  }, []);

  useEffect(() => {
    if (!ready) return;
    subscribe(onMessage);
    return () => {
      unsubscribe(onMessage);
    };
  }, [ready, subscribe, unsubscribe, onMessage]);

  return (
    <div>
      <p>Status: {status}</p>
      <button
        disabled={!ready}
        onClick={() => publish({ text: "Hello" }, { event: "chat" })}
      >
        Send
      </button>
    </div>
  );
}
```

```go
package main

import (
	"context"
	"fmt"
	"log"
	"os"

	"github.com/qpubio/qpub-go/channel"
	"github.com/qpubio/qpub-go/qpub"
)

func main() {
	socket := qpub.NewSocket(qpub.WithAPIKey(os.Getenv("QPUB_API_KEY")))
	defer socket.Reset()

	ctx := context.Background()
	if err := socket.Connection.WaitUntilConnected(ctx); err != nil {
		log.Fatal(err)
	}

	ch := socket.Channels.Get("news")
	err := ch.Subscribe(ctx, func(m qpub.Message) {
		fmt.Println(m.Data)
	}, channel.SubscribeOptions{})
	if err != nil {
		log.Fatal(err)
	}
}
```

</CodeExamples>

<When lang="javascript">
> Do not put a production API key secret in a public browser app. Use [token auth](/core/auth/token.mdx) instead.
</When>

<When lang="react">
For browsers, pass a JWT or [token request](/core/auth/token.mdx) into `SocketProvider` — not a secret API key in a public env var.
</When>

<When lang="go">
Run on a trusted server or backend. Keep the API key in environment variables; use [token auth](/core/auth/token.mdx) when issuing credentials to other clients.
</When>

</When>

<When group="REST">

Use the REST client for server publish, tokens, and queues:

<CodeExamples group="REST">

```javascript
import { QPub } from "@qpub/sdk";

const rest = new QPub.Rest({
  apiKey: process.env.QPUB_API_KEY,
});

await rest.channels.get("news").publish({ headline: "Ship it" });
```

```react
import { useState } from "react";
import { QPub } from "@qpub/sdk";

const rest = new QPub.Rest({
  apiKey: process.env.QPUB_API_KEY, // trusted / server-only env
});

export function PublishButton() {
  const [busy, setBusy] = useState(false);

  return (
    <button
      disabled={busy}
      onClick={async () => {
        setBusy(true);
        try {
          await rest.channels.get("news").publish({ headline: "Ship it" });
        } finally {
          setBusy(false);
        }
      }}
    >
      Publish
    </button>
  );
}
```

```go
package main

import (
	"context"
	"log"
	"os"

	"github.com/qpubio/qpub-go/channel"
	"github.com/qpubio/qpub-go/qpub"
)

func main() {
	rest := qpub.NewRest(qpub.WithAPIKey(os.Getenv("QPUB_API_KEY")))
	defer rest.Reset()

	_, err := rest.Channels.Get("news").Publish(
		context.Background(),
		map[string]string{"headline": "Ship it"},
		channel.PublishOptions{},
	)
	if err != nil {
		log.Fatal(err)
	}
}
```

</CodeExamples>

<When lang="javascript">
Keep the API key on a trusted server. Use [queues](/core/queue/index.mdx) and [token issue](/core/auth/token.mdx) from the same client.
</When>

<When lang="react">
QPub's React hooks/providers (`@qpub/sdk/react`) are Socket-only. REST is recommended for **server-side** use, so there's no dedicated React integration — but you can still call the plain `QPub.Rest` client from React (a server action or trusted backend). For browser realtime, switch to **Socket** and use `@qpub/sdk/react`.
</When>

<When lang="go">
REST and queues are a natural fit for Go services. See [qpub-go examples](https://github.com/qpubio/qpub-go/tree/main/examples) for queue workers and token flows.
</When>

</When>
