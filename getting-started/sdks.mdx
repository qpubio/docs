Use QPub's official SDKs to quickly integrate real-time features into your applications. Our SDKs are designed to simplify the complexity of real-time messaging, providing simple, intuitive interfaces that handle connection management, authentication, and error handling automatically.

## Available SDKs

QPub provides official SDKs for the most popular programming languages and platforms, each optimized for the specific ecosystem and following language conventions. The JavaScript/TypeScript SDK supports both browser and Node.js environments, making it perfect for web applications, React/Vue components, and server-side applications.

### JavaScript/TypeScript
```bash
npm install @qpub/socket-sdk @qpub/rest-sdk
```

The Python SDK is designed for backend services, data processing applications, and integration with popular frameworks like Django and Flask. It provides both synchronous and asynchronous interfaces, making it suitable for various Python application patterns.

### Python
```bash
pip install qpub-sdk
```

The Go SDK is optimized for high-performance applications, microservices, and concurrent systems. It provides efficient memory usage and excellent performance characteristics that match Go's strengths in building scalable backend services.

### Go
```bash
go get github.com/qpub/go-sdk
```

The Java SDK integrates seamlessly with enterprise applications, Spring frameworks, and Android development. It provides comprehensive support for Java's ecosystem and follows Java best practices for configuration and error handling.

### Java
```xml
<dependency>
  <groupId>com.qpub</groupId>
  <artifactId>qpub-java-sdk</artifactId>
  <version>1.0.0</version>
</dependency>
```

## JavaScript SDK Implementation

### Socket SDK for Real-time Features
```javascript
import { QPubSocket } from '@qpub/socket-sdk';

const client = new QPubSocket({
  apiKey: 'your-api-key'
});

// Subscribe to channel
client.subscribe('my-channel', (message) => {
  console.log('Received:', message);
});

// Publish message
client.publish('my-channel', {
  text: 'Hello, World!'
});
```

The JavaScript Socket SDK provides a simple interface for real-time communication. It handles WebSocket connections automatically, manages reconnection logic, and provides event-driven programming patterns that integrate well with modern JavaScript frameworks. The SDK includes TypeScript definitions for full type safety and excellent developer experience.

### REST SDK for Standard Operations
```javascript
import { QPubREST } from '@qpub/rest-sdk';

const client = new QPubREST({
  apiKey: 'your-api-key'
});

// Create channel
const channel = await client.createChannel({
  name: 'my-channel'
});

// Send message
await client.publish('my-channel', {
  text: 'Hello, World!'
});
```

The REST SDK provides Promise-based interfaces for standard HTTP operations. It's perfect for server-side applications, API integrations, and scenarios where you need to perform administrative tasks or send messages programmatically without maintaining persistent connections.

## Python SDK for Backend Services

```python
from qpub import QPubSocket

client = QPubSocket(api_key='your-api-key')

# Subscribe to channel
def on_message(message):
    print(f"Received: {message}")

client.subscribe('my-channel', on_message)

# Publish message
client.publish('my-channel', {
    'text': 'Hello, World!'
})
```

The Python SDK provides both synchronous and asynchronous interfaces, making it suitable for various application patterns. It integrates well with popular frameworks like Django, Flask, and FastAPI, and provides comprehensive error handling and logging capabilities.

## Go SDK for High-Performance Applications

```go
package main

import (
    "github.com/qpub/go-sdk"
)

func main() {
    client := qpub.NewSocketClient("your-api-key")
    
    // Subscribe to channel
    client.Subscribe("my-channel", func(message qpub.Message) {
        fmt.Printf("Received: %v\n", message)
    })
    
    // Publish message
    client.Publish("my-channel", map[string]interface{}{
        "text": "Hello, World!",
    })
}
```

The Go SDK is designed for high-performance, concurrent applications. It provides efficient memory usage, excellent performance characteristics, and integrates well with Go's concurrency patterns. The SDK handles connection pooling, automatic reconnection, and provides comprehensive error handling.

## SDK Features and Capabilities

All QPub SDKs share common features that simplify real-time application development. **Automatic Reconnection** handles connection failures gracefully, implementing exponential backoff and retry logic to ensure your applications remain connected even during network interruptions or server maintenance.

**Message Queuing** ensures that messages are not lost when connections are temporarily unavailable. The SDKs automatically queue outgoing messages when offline and deliver them once connectivity is restored, providing reliable message delivery even in unstable network conditions.

**Type Safety** is provided through comprehensive TypeScript definitions for JavaScript SDKs and strongly-typed interfaces for other languages. This helps catch errors at compile time and provides excellent IDE support with autocompletion and inline documentation.

**Error Handling** includes comprehensive error reporting, retry logic, and graceful degradation. The SDKs provide detailed error information to help with debugging while implementing sensible defaults for common failure scenarios.

**Documentation** is extensive and always up-to-date, with practical examples, best practices, and integration guides for popular frameworks and platforms.
