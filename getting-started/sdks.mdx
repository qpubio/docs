## JavaScript / TypeScript

**Package:** [`@qpub/sdk`](https://www.npmjs.com/package/@qpub/sdk)

```bash
npm install @qpub/sdk
# or
bun add @qpub/sdk
```

### Entry points

| Import | Use |
|--------|-----|
| `@qpub/sdk` | `QPub.Socket`, `QPub.Rest`, types |
| `@qpub/sdk/react` | React providers and hooks |
| CDN UMD | Global `QPub` (browser) |

### Socket client

```javascript
import { QPub } from "@qpub/sdk";

const socket = new QPub.Socket({ apiKey: process.env.QPUB_API_KEY });

socket.connection.on("connected", async () => {
  const ch = socket.channels.get("news");
  await ch.subscribe((msg) => console.log(msg.data));
});
```

### REST client

```javascript
import { QPub } from "@qpub/sdk";

const rest = new QPub.Rest({ apiKey: process.env.QPUB_API_KEY });
await rest.channels.get("news").publish({ headline: "Ship it" });
```

### React

```tsx
import { SocketProvider, useChannel, useConnection } from "@qpub/sdk/react";

function App() {
  return (
    <SocketProvider options={{ apiKey: process.env.NEXT_PUBLIC_QPUB_TOKEN_OR_KEY }}>
      <Chat />
    </SocketProvider>
  );
}

function Chat() {
  const { status } = useConnection();
  const { publish, subscribe, unsubscribe, ready } = useChannel("chat");

  // Subscribe when ready; clean up on unmount
  // ...
  return <div>Status: {status}</div>;
}
```

Prefer issuing a JWT or token request for browser apps — see [Token Auth](/core/auth/token).
