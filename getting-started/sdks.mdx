QPub’s official client library is `@qpub/sdk` for JavaScript and TypeScript (browsers, Node.js, Bun, and React). Use the **Examples** controls to switch **Socket** vs **REST** and **JavaScript** vs **React**.

<ExampleScope defaultGroup="Socket" groups={["Socket", "REST"]} languages={["javascript", "react"]}>

## Install

```bash
npm install @qpub/sdk
# or
bun add @qpub/sdk
```

| Import | Use |
|--------|-----|
| `@qpub/sdk` | `QPub.Socket`, `QPub.Rest`, types |
| `@qpub/sdk/react` | React providers and hooks |
| CDN UMD | Global `QPub` in the browser |

<When lang="react">
Import providers and hooks from `@qpub/sdk/react` (same package).
</When>

## Quick example

<When group="Socket">

Use the Socket client for realtime subscribe and publish:

<CodeExamples
  codeSnippets={{
    Socket: {
      javascript: `import { QPub } from "@qpub/sdk";

const socket = new QPub.Socket({
  apiKey: process.env.QPUB_API_KEY,
});

socket.connection.on("connected", async () => {
  const ch = socket.channels.get("news");
  await ch.subscribe((msg) => console.log(msg.data));
});`,
      react: `import { useCallback, useEffect } from "react";
import {
  SocketProvider,
  useChannel,
  useConnection,
  type Message,
} from "@qpub/sdk/react";

function App({ tokenRequest }) {
  return (
    <SocketProvider options={{ tokenRequest }}>
      <Chat />
    </SocketProvider>
  );
}

function Chat() {
  const { status } = useConnection();
  const { publish, subscribe, unsubscribe, ready } = useChannel("chat");

  const onMessage = useCallback((message: Message) => {
    console.log(message.data);
  }, []);

  useEffect(() => {
    if (!ready) return;
    subscribe(onMessage);
    return () => {
      unsubscribe(onMessage);
    };
  }, [ready, subscribe, unsubscribe, onMessage]);

  return (
    <div>
      <p>Status: {status}</p>
      <button
        disabled={!ready}
        onClick={() => publish({ text: "Hello" }, { event: "chat" })}
      >
        Send
      </button>
    </div>
  );
}`,
    },
  }}
/>

<When lang="javascript">
> Do not put a production API key secret in a public browser app. Use [token auth](/core/auth/token.mdx) instead.
</When>

<When lang="react">
For browsers, pass a JWT or [token request](/core/auth/token.mdx) into `SocketProvider` — not a secret API key in a public env var.
</When>

</When>

<When group="REST">

Use the REST client for server publish, tokens, and queues:

<CodeExamples
  codeSnippets={{
    REST: {
      javascript: `import { QPub } from "@qpub/sdk";

const rest = new QPub.Rest({
  apiKey: process.env.QPUB_API_KEY,
});

await rest.channels.get("news").publish({ headline: "Ship it" });`,
      react: `import { useState } from "react";
import { QPub } from "@qpub/sdk";

const rest = new QPub.Rest({
  apiKey: process.env.QPUB_API_KEY, // trusted / server-only env
});

export function PublishButton() {
  const [busy, setBusy] = useState(false);

  return (
    <button
      disabled={busy}
      onClick={async () => {
        setBusy(true);
        try {
          await rest.channels.get("news").publish({ headline: "Ship it" });
        } finally {
          setBusy(false);
        }
      }}
    >
      Publish
    </button>
  );
}`,
    },
  }}
/>

<When lang="javascript">
Keep the API key on a trusted server. Use [queues](/core/queue/index.mdx) and [token issue](/core/auth/token.mdx) from the same client.
</When>

<When lang="react">
Call REST from a server action or trusted backend. For browser realtime, switch to **Socket** and use `@qpub/sdk/react`.
</When>

</When>
