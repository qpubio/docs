Channel handles are how Socket clients subscribe and publish.

## Manager (`socket.channels`)

| Method | Description |
|--------|-------------|
| `get(name)` | Channel handle for `name` |
| `has(name)` | Whether a handle exists |
| `release(name)` | Drop local handle (ref-count) |
| `remove(name)` | Remove handle |

## Channel methods

<ExampleScope defaultGroup="Socket" groups={["Socket"]} languages={["javascript", "typescript", "react", "go"]}>

<CodeExamples group="Socket">

```javascript
const channel = socket.channels.get("demo");

await channel.subscribe((message) => {
  console.log(message.data, message.event);
}, { event: "optional-filter", timeout: 10000 });

await channel.publish({ hello: true }, { event: "ping", alias: "bot" });

await channel.unsubscribe(); // whole channel
await channel.unsubscribe(handler, { event: "optional-filter" });

channel.pause({ bufferMessages: true });
channel.resume();
```

```react
import { useEffect } from "react";
import { useChannel } from "@qpub/sdk/react";

function Demo() {
  const { subscribe, publish, unsubscribe, ready } = useChannel("demo");

  useEffect(() => {
    if (!ready) return;
    const onMessage = (message) => console.log(message.data);
    subscribe(onMessage, { event: "optional-filter" });
    return () => unsubscribe(onMessage);
  }, [ready, subscribe, unsubscribe]);

  return (
    <button
      disabled={!ready}
      onClick={() => publish({ hello: true }, { event: "ping" })}
    >
      Publish
    </button>
  );
}
```

```go
import (
	"context"

	"github.com/qpubio/qpub-go/channel"
)

ch := socket.Channels.Get("demo")
_ = ch.Subscribe(ctx, func(m qpub.Message) {
	// handle message
}, channel.SubscribeOptions{Event: "optional-filter"})

_ = ch.Publish(ctx, map[string]bool{"hello": true}, channel.PublishOptions{
	Event: "ping",
	Alias: "bot",
})
```

| Method | Description |
|--------|-------------|
| `subscribe(handler, options?)` | Subscribe; resolves on ack. Options: `event`, `timeout` (default 10s) |
| `unsubscribe(handler?, options?)` | Unsubscribe all or one event handler |
| `publish(data, options?)` | Publish over WebSocket |
| `pause(options?)` | Pause delivery locally |
| `resume()` | Resume |
| `resubscribe()` | Re-subscribe with existing callbacks (for reconnection) |
| `isSubscribed()` | Whether channel is actively subscribed |
| `isPaused()` | Whether delivery is paused |
| `hasCallback()` | Whether a message callback is registered |
| `clearBufferedMessages()` | Drop buffered messages without delivery |
| `on(event, handler)` | Channel lifecycle events |

Event filters are applied in the SDK after a full-channel subscription.

## Message callback

Fields commonly used by apps: `channel`, `event`, `data`, `alias`, `id`, `timestamp`.

## Channel events

`initialized`, `subscribing`, `subscribed`, `unsubscribing`, `unsubscribed`, `paused`, `resumed`, `failed`.
