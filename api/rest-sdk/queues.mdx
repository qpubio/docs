Access via `rest.queues` (`IRestQueueManager`). Wire JSON uses snake_case; the SDK exposes camelCase.

<ExampleScope defaultGroup="REST" groups={["REST"]} languages={["javascript", "typescript", "go", "curl"]}>

<CodeExamples group="REST">

```javascript
await rest.queues.enqueue("emails", { to: "user@example.com" });
const job = await rest.queues.getJob("emails", jobId);
```

```typescript
await rest.queues.enqueue("emails", { to: "user@example.com" });
```

```go
_, err := rest.Queues.Enqueue(ctx, "emails", payload, protocol.EnqueueOptions{})
```

```curl
API_KEY="publicId:secret"
curl -X POST "https://rest.qpub.io/v1/queue/emails/jobs" \
  -H "Authorization: Basic $(echo -n "$API_KEY" | base64)" \
  -H "Content-Type: application/json" \
  -d '{"payload":{"to":"user@example.com"}}'
```

## Jobs

| Method | Description |
|--------|-------------|
| `enqueue(name, payload, opts?)` | Create a job |
| `getJob(name, jobId)` | Fetch one job |
| `listJobs(name, opts?)` | List jobs (`status` filter) |
| `cancelJob(name, jobId)` | Cancel |
| `retryJob(name, jobId)` | Retry |

`EnqueueOptions`: `delay`, `idempotencyKey`, `scheduleAt`, `metadata`.

## Config

| Method | Description |
|--------|-------------|
| `getConfig(name)` | Read queue config |
| `updateConfig(name, opts)` | Create queue if missing (`maxAttempts`, webhooks); no field updates if it already exists |

See [Jobs](/core/queue/jobs.mdx#queue-config) for current PUT behavior.

## Workers

| Method | Description |
|--------|-------------|
| `registerWorker({ name, queues })` | Register worker metadata |
| `heartbeat(workerId)` | Heartbeat |
| `runWorker(name, handler, opts?)` | Long-poll loop (blocks until stop) |
| `stopWorker()` | Stop the loop |

`RunWorkerOptions`: `workerId`, `batchSize`, `pollIntervalMs`, `wait`, `heartbeatIntervalMs` (default 20 000 ms).

Conceptual guide: [Queue](/core/queue/index.mdx).
